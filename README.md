# 捞鱼 C 盘清理
为不想折腾电脑的人准备的空间诊断工具。

## 0.1.0 Windows 测试版
下载 `LaoyuCleaner-Windows.zip`，解压到任意目录，双击根目录 `LaoyuCleaner.exe`；无须安装 Python、Node 或管理员权限。不要只复制 EXE，需要保留同目录的依赖。

1. 点击空间诊断（只读）。
2. 看每项路径、依据和估算，默认没有勾选项。
3. 基础项只处理固定用户 Temp 根层超过 7 天的 .tmp/.temp，以及旧 .dmp 转储；不扫全盘扩展名。
4. 进阶缓存逐项选择，关闭相关应用；网络下载/编译缓存未来可能重建。
5. 用户确认后仅移到回收站。个人文档、下载、桌面和系统核心不自动清理。

### 恢复
Windows 打开回收站，找到项目，右键还原。先确认应用正常，再自行决定是否清空回收站。软件不会清空，也不会将移动量冒充已释放空间；系统或其他清理工具可能自动清空，清空后恢复不保证。

### 我们的区别
- 告诉你空间在哪里，不把大目录统称“垃圾”。
- 每项有理由、范围、确认与结果，没有自动全盘大扫除。
- 提供迁移 Prompt：让 Agent 先只读评估、确认、备份、复制核验与回滚；本软件不自动迁移。
- 离线诊断、不上传路径或文件、无驻留扫描。日志仅本机分类汇总。
- 每日首启查询固定官方仓库的正式新版，可手动重试；首版手动下载升级，未实现自动安装。

### 已验收与平台状态
Windows x64：22 项隔离测试、打包界面冒烟、真实测试文件回收站/还原及哈希一致通过。普通文件权限/锁定问题会跳过或报失败，扫描有预算，会标记不完整。路径检查与系统回收站移动非原子事务，不承诺对恶意并发替换的绝对防护。
macOS：已实现明确缓存规则与同一界面，规则模拟测试通过；x64/Apple Silicon 构建和 Mac 实机验收仍在进行，当前 Windows ZIP 不适用于 Mac。
首次版本仍标测试版，代码签名、Mac 签名公证和完整一键升级尚未完成。

Mac 调研参考 [Mole](https://github.com/tw93/Mole) 与 [BleachBit](https://github.com/bleachbit/bleachbit)，清理引擎独立实现，没有复制或打包上游全量删除脚本。
